    4Theory in Brief

    What is a Right-Linear Grammar?

    G = (V, T, P, S) where every production is A → wB or A → w: a non-terminal may appear only at the right end. This tool uses the normal form A → aB | a | ε. RLGs generate exactly the regular languages.

    What is an NFA?

    M = (Q, Σ, δ, q₀, F) with δ : Q × Σ → 2Q. A state may have several (or no) moves on a symbol. A string is accepted if at least one path ends in a final state.

    How does RLG convert to NFA?

    Q = V ∪ {F}, q₀ = S, Σ = T. For A → aB add B to δ(A, a); for A → a add F to δ(A, a); for A → ε put A in the final set. Final set = {F} ∪ ε-states.

    Meaning of A → aB, A → a and the final state

    A → aB: read a, continue from B. A → a: read a and stop in F. The final state decides acceptance after the whole string is read. (If the grammar already has a non-terminal named F, the final state is shown as qf.)
